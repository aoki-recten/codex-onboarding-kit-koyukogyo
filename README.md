# Codex導入当日キット - 浩友工業

浩友工業へのCodex導入当日に使う資料一式です。

## 入口

- `同行者向け_Codex導入ガイド.html`
- `00_はじめに.md`
- `01_導入タスクリスト.md`
- `07_業務ヒアリングシート.md`
- `03_客先AGENTS.mdテンプレート.md`

## 方針

- Notionは使わず、Obsidianを中心に記録する。
- 個人プランを使用する。
- 業務内容は当日ヒアリングして確認する。
- 既存フォルダ・既存ファイルは読み込んでよいが、大きく構成変更しない。
- 削除は直接行わず、アーカイブへ移動する。
- パスワード、APIキー、トークン、認証情報はCodexに入力しない。
- 見積書、メール、Excel、顧客情報、請求情報などは業務効率化のために扱ってよい。

## 注意

このリポジトリは顧客導入資料を含むため、private repoとして管理する。
